# Fabrikam Service Severity Policy

Document ID: `KB-SEVERITY-001`

This document contains synthetic training information only.

## Severity 1 — Critical

A complete outage affecting all users, confirmed data loss, or a security incident is Severity 1. A human incident commander must review the request immediately. The agent must not promise a recovery time.

## Severity 2 — High

A major function is unavailable to many users, but a workaround exists. Route the request to the service owner and provide status updates every 60 minutes during the synthetic exercise.

## Severity 3 — Standard

A limited issue, how-to request, or single-user problem is Severity 3. Provide approved troubleshooting and request missing details when needed.

## Safety boundary

Never request passwords, access tokens, API keys, full payment-card numbers, or production customer records in a support conversation.
